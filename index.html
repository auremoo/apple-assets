Sauvegarde DataSafe

Configurez votre compte DataSafe pour sauvegarder automatiquement vos données à chaque modification. Cette configuration n'est jamais codée en dur dans l'app : elle est saisie ici et stockée sur cet appareil. Si elle est active, votre clé API est aussi incluse dans vos sauvegardes JSON (push et téléchargement) afin qu'un réimport restaure automatiquement la connexion — gardez donc ces fichiers en lieu sûr.
